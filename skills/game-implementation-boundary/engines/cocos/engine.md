## Source Path

- `D:\engine\cocos\cocos-engine-3.8.7\cocos-engine-3.8.7`
- Note the nested folder with the same name; the engine sources (`cocos/`, `editor/`, `package.json`) are in the inner folder.
- If this path is unavailable or the relevant source cannot be found there, stop and ask the user for the correct engine source path before continuing.

## Detection

- Project root has `assets/`, and has `settings/` or a `package.json` with a `creator` field.
